## Overview

**Credit risk** is an important challenge in consumer lending. Financial institutions need to identify loan applications that may lead to future repayment difficulties using information available at the time of the loan decision.

In this competition, participants are challenged to build a model that **predicts the probability** of serious repayment difficulty in an Indonesian consumer lending environment.

A loan is considered to experience serious repayment difficulty when its end-of-day **Days Past Due (DPD**) reaches 90 or more within 12 calendar months after origination.

---

# Competition Objective

The objective is to develop a predictive model that can effectively distinguish between loans that experience serious repayment difficulty and those that do not.

The competition uses the **Kolmogorov–Smirnov (KS) statistic** to evaluate how well the predicted risk scores separate the two classes. A higher KS score indicates better separation between higher-risk and lower-risk loans.

Participants are encouraged to explore the data, combine relevant information from multiple sources, and develop meaningful features that capture customer financial and behavioral patterns while avoiding data leakage.

### Evaluation

Participant performance will be evaluated using the **Kolmogorov-Smirnov (KS) Statistic**.

The KS Statistic measures the ability of a model to distinguish between loans that experience **serious repayment difficulty** and those that do not, based on the predicted probabilities generated by the model.

In this competition, serious repayment difficulty is defined as a loan reaching **90 or more days past due (DPD) within 12 calendar months after origination**.

In general, the KS Statistic is calculated as the maximum difference between the cumulative distributions of predicted scores for the two groups:



| KS = \max_s \|F_1(s) - F_0(s)\| |
| ------------------------------- |

where:

- **F₁(s)** represents the cumulative distribution of predicted scores for loans that experience serious repayment difficulty.
- **F₀(s)** represents the cumulative distribution of predicted scores for loans that do not experience serious repayment difficulty.
- **s** represents the predicted probability or risk score generated by the model.

A higher KS value indicates better ability of the model to distinguish between loans that experience serious repayment difficulty and those that do not.
```python
### Evaluation Code
import numpy as np
import pandas as pd
from scipy.stats import ks_2samp

def score(solution: pd.DataFrame, submission: pd.DataFrame, row_id_column_name: str) -> float:
    """
    Menghitung skor KS (Kolmogorov-Smirnov) dua sampel antara kelas positif dan negatif.
    """
    target_col = "default_probability"

    sol = solution.sort_values(by=row_id_column_name).reset_index(drop=True)
    sub = submission.sort_values(by=row_id_column_name).reset_index(drop=True)

    y_true = sol[target_col].to_numpy()
    y_pred = sub[target_col].to_numpy()

    preds_bad = y_pred[y_true == 1]   # Nasabah gagal bayar
    preds_good = y_pred[y_true == 0]  # Nasabah lancar

    if len(preds_bad) == 0 or len(preds_good) == 0:
        return 0.0

    ks_result = ks_2samp(preds_bad, preds_good)

    return float(ks_result.statistic)

```
