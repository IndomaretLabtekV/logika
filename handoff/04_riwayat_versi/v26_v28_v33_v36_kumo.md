# Kumo-Tabular (17–18 Okt): v26, v28, v30, v33, v36

NVIDIA Kumo-Tabular (paket `structured-data-models` 0.2.1, `sdm.models.KumoTabular(task="classification",
size="large")`, ~200M parameter, bobot fp32 816 MB) adalah in-context learner: tidak ada training, context = baris train
berlabel, query = baris yang diprediksi. Input = `valid2.fm_select` (100 numerik + 4 kategori sebagai integer code),
4 estimator, fp16 autocast, query di-chunk 1.000.
