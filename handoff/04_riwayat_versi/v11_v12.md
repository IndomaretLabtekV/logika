# v11 dan v12: tuning dan kapasitas TabM (16 Okt, Kaggle T4)

Kernel: https://www.kaggle.com/code/riantamaputra/logika-v11-tabm-tuning dan
https://www.kaggle.com/code/riantamaputra/logika-v12-tabm-capacity. Builder `notebook/build_v11.py`,
`build_v12.py`; kode `notebook/v11_experiment.py` (v12 = v11 dengan grid/model/output diubah lewat AST).
Hasil `results/v11/v11/`, `results/v12/v12/` (oof.parquet, submission_*.csv = prediksi test, inner_trials.csv,
kurva per epoch `curve_f*_*.csv`, learning_curves.png). Paket dipin: tabm 0.0.3, rtdl_num_embeddings 0.0.12.

## Protokol (bersih)
5 outer fold (seed 42). Di tiap outer train: split stratified 80/20; epoch terbaik dipilih dari AUC inner (maks 60,
patience 8), konfigurasi dipilih dari KS inner; lalu control dan konfigurasi terpilih di-refit di seluruh outer train
dengan epoch tetap. Label outer tidak dipakai. 1 seed. Fitur `eda/features.py`, input `eda/nn_prep.py` fold-local.

## v11: optimizer
Kandidat: control (lr .002, wd .0003, 48 bin), lr .0005, wd .01, 16 bin.

| | Pooled OOF KS |
|---|---|
| control | 0,517518 |
| tuned | 0,519927 |
| Δ | +0,0024, bootstrap 95% [−0,0012, +0,0056]; per fold 0, −0,0005, −0,0036, +0,0031, +0,0060 → tidak dipromosikan |

Campuran 80% v8 + 20% tuned: 0,526246 (−0,0008 vs v8).

**Temuan kurva:** AUC inner memuncak sangat dini lalu turun, sementara loss training terus turun (fold 0 control:
epoch terbaik 6, AUC 0,84434; epoch 14 0,84073). TabM overfit cepat → pilihan epoch sangat sensitif → di v8 (stop di
fold validasi) OOF TabM jadi optimis.

## v12: kapasitas
Kandidat: control, d_block 128, n_blocks 1, dropout 0,3 (lr/wd/bins tetap).

| | Pooled OOF KS |
|---|---|
| control | 0,518629 |
| tuned | 0,519172 |
| Δ | +0,0005 |

Ditambahkan ke stack v8 (bench 20×2): −0,0003. Null.

## Pelajaran
- TabM bersih ~0,518–0,520, jauh di bawah TabM v8 0,5257 → bukti utama bias OOF v8.
- Tuning optimizer/kapasitas tidak memperbaiki apa-apa secara meyakinkan.
