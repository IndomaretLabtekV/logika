# v14: hybrid raw-event set network (16 Okt, Kaggle T4)

Kernel: https://www.kaggle.com/code/riantamaputra/logika-v14-hybrid-events (version 2; version 1 crash karena
`yt[i]` diakses untuk baris test). Builder `notebook/build_v14.py`, kode `notebook/v14_experiment.py`. Hasil
`results/v14/v14/` (oof.parquet + test.parquet dengan ID, kolom hybrid/events).

## Ide
Kalau ada informasi yang hilang karena agregasi manual, model yang membaca **baris mentah** semua tabel harusnya
menemukannya.

## Model
Encoder set berbasis attention per tabel atas baris mentah sebelum cutoff: 128 item e-commerce, 64 cicilan, 24 bulan
akun, 16 laporan bureau, 16 aplikasi lama. Varian:
- `events`: hanya encoder event;
- `hybrid`: encoder event + fitur manual (nn_prep fold-local).
5 fold × 3 seed, early stopping di 10% inner split (bersih).

## Hasil
| Model | OOF KS | + ke stack v8 9-model (held-out 20×2) |
|---|---|---|
| hybrid | 0,5187 | −0,0012 (LR stack), −0,0002 (bobot tetap) |
| events | 0,5107 | −0,0012 / −0,0001 |

`events` (tanpa satu pun fitur manual) mencapai 0,511 dengan korelasi rank 0,95 terhadap TabM, tapi tetap tidak
menambah apa-apa.

## Pelajaran
Bukti kuat bahwa informasi yang bisa diekstrak dari tabel mentah sudah tertangkap fitur v5–v8. Sisi fitur memang
jenuh. Juga dihitung: sd selisih KS dua model di subset 13,5k baris 0,0026 (TabM vs stack) sampai 0,0055 (events vs
stack) → gap +0,016 ke top-1 tidak bisa dijelaskan oleh variasi satu tim.
